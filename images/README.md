# 🧪 FRAS Test Images

This folder contains the **test image files** used to evaluate and train the **FRAS (Facial Recognition Attendance System)** during development.

---

## 🎯 Purpose

These images are used for:
- Testing the facial recognition accuracy of the FRAS system.
- Simulating different user inputs during registration and attendance.
- Validating detection and recognition processes under various lighting and background conditions.

---

## ✅ Image Guidelines

To ensure optimal performance of the FRAS system, test images should follow these guidelines:

- **Format**: JPEG (.jpg) or PNG (.png)
- **Resolution**: Minimum 640x480 recommended
- **Lighting**: Good lighting conditions with clear facial visibility
- **Face Positioning**:
  - Full front-facing images are preferred
  - Minimal background clutter
  - No masks, sunglasses, or strong shadows

---

## 📌 Usage Notes

- These images are referenced by all .py file for encoding, testing, and registration.
- Add your new images here when registering a new user.
- Make sure image filenames match the names used in your database (e.g., `StudentID.jpg`).

---

## 🔒 Privacy Notice

All individuals included in these images are from the internet for development and testing purposes.
