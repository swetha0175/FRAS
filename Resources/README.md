# 📁 FRAS Resources

This directory contains **visual resources** used in the **FRAS (Facial Recognition Attendance System)** project. These include images, screenshots, and UI/UX designs that showcase the interface and functionality of the system.

---

## 📌 Purpose

The contents in this folder are intended to:
- Demonstrate the look and feel of the FRAS user interface.
- Show how the system operates in `FRAS-main-system`.
- Support presentations of the `FRAS-main-system` for the FRAS project.
